## 测试口径

实际运行记录见 机器可读验收结果（原本地引用：`../artifacts/acceptance/results.json`；目标未随本次文档归档上传）。`npm run agriculture:check` 同时执行 TypeScript 全项目检查、旧运行路径残留检查、12 来源目录校验和八场景证据检查；`npm run agriculture:test` 执行领域、来源、流程和输出测试。

端到端测试包括：无事件允许空关注；缺失不填零；预报不填水温；冲突记录排除；不确认批次时不输出依赖物种阶段的建议；天气地区不匹配不关联；未知地区降为待核实；取消事件不被旧消息恢复；模型伪造数值/链接/引用或省略限制均被拦截；截断、空输出和超时重试受限；未授权对象在模型前被拒绝；目录提交原子化；重名和并发不覆盖；篡改及重新计算部分 hash 后的语义错配仍被检出。

同一场景和时钟的 snapshot、evidence、report 内容可重放一致。manifest 记录真实耗时和模型尝试，故 manifest hash、与其绑定的候选包 hash 不要求每次相同。所有候选默认 `needs_review`，自动校验不等于专业人员审批。

原始项目没有统一 `test` 脚本；本轮没有运行原 `daily`、真实采集或模型入口来假充基线验收。依赖已在开发副本安装，新增检查均基于本副本锁文件执行。首次沙箱执行 tsx 因 Windows `uv_os_get_passwd ENOMEM` 无法启动，获准在普通进程重跑；该环境错误不计作测试通过。

## 界面验收范围

HTML 自动检查覆盖转义、安全链接、本地证据锚点、合成标记、无事件与缺口呈现。浏览器工具尝试两次都因 `Unable to load browser request-header policy` 无法启动，因此本轮不声称已经完成浏览器截图或不同屏幕尺寸的视觉验收。可直接双击生成的 `report.html` 查看。

## 后续边界

12 组真实来源均尚未通过抓取验收；模拟证据不属于那些机构发布的内容。真实 LLM、来源授权和频率验证、专业规则阈值、梁子湖平台导出/导入接口、认证与权限集成、任务写回、部署通知均未实施。本轮不产生真实农艺处方或设备动作。

候选包 schema 是本轮提出并实现的协议草案，字段对齐平台现有对象、批次和测值语义，不声称平台已经支持它。hash 不具有签名或身份认证作用；未来导入必须在服务端重新校验授权、有效期、来源和人员审核。
