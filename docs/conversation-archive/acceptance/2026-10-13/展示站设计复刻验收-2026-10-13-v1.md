# 展示站设计复刻验收

日期：2026-10-13。版本：v1。本次只修改展示产品，不调用收费模型，不改变真实采集数据。

## 设计修正

参考图：[智慧农业情报地图仪表盘](https://github.com/No1dry/transfer/blob/main/智慧农业情报地图仪表盘.png)。移除导航，采用左列表和右地图两区；详情嵌套在地图内绝对定位，不再占第三列。主区贴边铺满，分类独立白卡，恢复中性灰文字与橙色操作。

重新绘制搜索、加号、专题、导出、政策、论文、气象、农技、设备、图层、定位、缩放、方向、关闭、原文、星标等 SVG 图标。分类计数、折叠、标签、地图概览和比例尺按参考图组织。

删除上下工程状态栏、Kimi/tokens/调用量/源码入口、常显哈希、N/A和未接入模块；摘要改为内容摘要。工程诊断仍保留在引擎运行记录。图片中的虚构田塘边界、面积及关联数未移植。

## 产品交互

搜索、分类折叠与分类内滚动；文章选择及详情关闭；同类资料跳转；浏览器内持久保存已选简报和专题；页面内生成简报；Markdown 导出；天气/概览图层开关；地图缩放与返回区域。

专题用于定制当前浏览器首页，不声称已开通邮件或消息推送。生成简报组合已有真实摘要，浏览器不持有模型凭证。

## 已做验证

- 8 项已有数据、发布与界面边界检查通过；静态构建通过。
- 桌面实际视口 1309px，对照参考图检查颜色、卡片密度、图标、地图内浮层及底部操作。
- 关闭详情前后地图 x=416.28、宽度893px，保持一致，确认不是独立第三列。
- 无匹配搜索隐藏详情，清除筛选后恢复；分类折叠状态切换正常。
- 真实文章加入简报后，弹窗显示对应摘要；刷新后选中简报和专题偏好仍保存。
- 天气图层可开关，详情关闭后地图控件可访问。
- 手机实际视口355px，文档宽度355px，无横向溢出；在地图内显示可滚动详情，键盘激活关闭正常。浏览器翻译浮标会遮住部分右上角区域，未更改用户扩展设置。
- 页面控制台未捕获错误。导出处理函数执行，但自动化未捕获 Blob 下载事件，指定默认下载路径也未找到文件，因此不把实际文件落盘记为已验证。

## 还原边界

参考提供的是位图，没有独立 SVG、字体或照片素材。界面图标按图重新绘制，未声称与原图原始矢量逐像素一致。真实内容的数量、文本、地图位置不同，未将设计图示例数据伪装成真实数据。没有核实到原文照片的文章使用分类图形；NMC 当期周报使用已验证的官方正文配图。

## 发布核验

版本经独立分支核验后发布到 [展示站](https://no1dry.github.io/AgriTwin-Showcase/)，以最终 GitHub Actions 部署状态及公开页面核验为准。GitHub 合并界面持续报错时，采用先提交新测试阻止不完整版本部署、再提交资源和文档、最后提交新版页面的顺序更新主分支。相应部署链接在本次归档清单的 release 字段记录。
