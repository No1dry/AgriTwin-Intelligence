## 重新运行

在开发项目目录执行，运行名称必须是未用过的新名称：

```powershell
npm run agriculture:collect -- --mode live --run-id my-source-collection --max-articles 2
npm run agriculture:source-report -- --collection artifacts/source-collections/my-source-collection/collection.json --run-id my-source-report
npm run agriculture:validate -- --bundle artifacts/agriculture/my-source-report/candidate-bundle.json
```

第一条命令进行公开网页读取；后两条仅用本地缓存和确定性规则。默认 demo 继续使用离线 MOCK/合成资料，两个流程不混淆。

第 9 步没有接入真实模型、传感器、天气账号或梁子湖平台，没有派单、自动控制或部署通知。报告中的观测、批次、天气和任务依然是模拟数据；真实资料不能据此直接变成本场生产建议。

下一阶段是对同一封存输入进行真实模型的引用准确性、拒答、超时和成本验收；天气、论文及平台适配按后续计划逐项推进。
